# Переход с Uno на native Android

После проверки актуального Android SDK принято решение перейти на нативный Kotlin + Jetpack Compose.

Причины:

- приложение Android-only;
- требуется наиболее точный контроль SensorManager и foreground service;
- Android 16 уже является целевой современной платформой;
- Compose является основным направлением дальнейшего развития Android UI;
- Material 3 уже содержит современные адаптивные и expressive-направления.

Uno можно оставить как отдельный эксперимент, но он больше не является основой продукта «Шагомер».

## Версии на 15 августа 2026

- AGP 9.0.1.
- Compose Material 3 stable 1.4.0; expressive API развиваются в 1.5 alpha.
- Compose BOM 2026.06.00.
- Health Connect 1.1.0 stable.
- Room 3.0 уже стабилен, однако первая native-итерация намеренно использует прямой SQLiteOpenHelper: это уменьшает количество генераторов кода и зависимостей на этапе переноса/импорта.

Переход на Room 3 разумно сделать после стабилизации схемы данных.
